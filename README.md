# اپ‌ساز فارسی

نسخه آزمایشی ۰.۱ از محیط شخصی ساخت برنامه به زبان فارسی.

## امکانات فعلی

- رابط کاربری فارسی و راست‌چین
- داشبورد ساده
- ایجاد پروژه با نام دلخواه
- نمایش و حذف پروژه‌ها
- ذخیره پروژه‌ها در حافظه محلی مرورگر
- طراحی واکنش‌گرا برای موبایل

## فناوری‌ها

- React
- TypeScript
- Vite

## اجرای پروژه

ابتدا Node.js را نصب کن، سپس در پوشه پروژه اجرا کن:

npm install

npm run dev

برای ساخت نسخه نهایی:

npm run build

## وضعیت توسعه

این فقط اسکلت اولیه پروژه است.

هنوز ویرایشگر بصری، بلوک‌های برنامه‌نویسی،
دستیار هوش مصنوعی و خروجی‌گیر ساخته نشده‌اند.
